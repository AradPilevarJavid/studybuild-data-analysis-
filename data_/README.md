# Data Directory

## Raw Data

The raw data files are sourced from the **CASdatasets** R package:

- **Source:** https://dutangc.github.io/CASdatasets/reference/freMTPL.html
- **Dataset:** French Motor Third-Party Liability (freMTPL2)
- **Policies:** 678,000+ motor third-party liability policies (observed 2011–2013)
- **Original author:** Unknown private insurer (provided via CASdatasets)

### Files

| File | Rows | Description |
|---|---|---|
| `freMTPL2freq.csv` | 678,013 | Policy-level frequency data with risk features |
| `freMTPL2sev.csv` | 26,639 | Claim-level severity data with claim amounts |

### Key Variables (Frequency Table)

| Variable | Type | Description |
|---|---|---|
| `IDpol` | float | Policy ID (unique identifier) |
| `ClaimNb` | int | Number of claims during exposure period |
| `Exposure` | float | Exposure period in years (0–2+) |
| `VehPower` | int | Vehicle power (horsepower category) |
| `VehAge` | int | Vehicle age in years |
| `DrivAge` | int | Driver age in years |
| `BonusMalus` | int | Bonus-malus score (50 = best, 230 = worst) |
| `VehBrand` | str | Vehicle brand category (B1–B14) |
| `VehGas` | str | Fuel type (Regular or Diesel) |
| `Area` | str | Density category (A = rural to E = urban) |
| `Density` | int | Population density of policy area |
| `Region` | str | French policy region |

### Key Variables (Severity Table)

| Variable | Type | Description |
|---|---|---|
| `IDpol` | int | Policy ID (links to frequency table) |
| `ClaimAmount` | float | Individual claim cost in euros |

## Processed Data (Tableau-Ready)

Generated by `notebooks/analysis.ipynb`:

| File | Description |
|---|---|
| `tableau_policy_level.csv` | Full policy-level dataset with engineered segments |
| `tableau_regional_kpi.csv` | Regional KPI summary |
| `tableau_segment_analysis.csv` | Segment-level KPI analysis (driver age, vehicle age, etc.) |
| `tableau_individual_claims.csv` | Individual claims with cumulative cost for Pareto analysis |
| `tableau_portfolio_kpi.csv` | Portfolio-level KPI summary for dashboard cards |
